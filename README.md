# BOARDSPORT - E-commerce Приложение

Современное e-commerce приложение для экстремальных видов спорта, разработанное на React с использованием Tailwind CSS.

## 🎯 Структура проекта

```
boardsport-app/
├── components/              # Переиспользуемые компоненты
│   ├── Header.jsx          # Хедер с навигацией и поиском
│   ├── HeroSection.jsx      # Банер с промо акцией
│   ├── BrandSlider.jsx      # Слайдер брендов
│   ├── ProductCard.jsx      # Карточка товара
│   ├── CategorySection.jsx  # Секция категории товаров
│   └── Footer.jsx           # Футер с контактами
│
├── data/                    # Mock данные и типы
│   └── mockData.js         # Товары, бренды, категории
│
├── BoardSportApp.jsx        # Главный компонент приложения
├── index.jsx                # Входная точка
├── index.css                # Глобальные стили
├── index.html               # HTML файл
│
├── vite.config.js           # Конфиг Vite
├── tailwind.config.js       # Конфиг Tailwind CSS
├── postcss.config.js        # PostCSS конфиг
├── package.json             # Зависимости проекта
└── .gitignore              # Файлы для игнорирования
```

## 🚀 Установка и запуск

### Требования
- Node.js 16+ 
- npm или yarn

### Быстрый старт

1. **Установить зависимости:**
```bash
npm install
```

2. **Запустить dev сервер:**
```bash
npm run dev
```

3. **Открыть в браузере:**
```
http://localhost:3000
```

4. **Собрать production версию:**
```bash
npm run build
```

## 📦 Основные компоненты

### `Header` - Навигация и поиск
- Фиксированный заголовок со стрелкой
- Логотип по центру
- Функция поиска
- Счетчик товаров в корзине
- Адаптивный дизайн

### `HeroSection` - Промо баннер
- Анимированные элементы фона (blob animations)
- Текст "WINTER SALE ДО -70%"
- CTA кнопка для перехода к предложениям

### `BrandSlider` - Слайдер брендов
- Прокручиваемый список брендов
- Навигационные стрелки
- Скрытый scrollbar

### `ProductCard` - Карточка товара
- Изображение товара
- Бейдж с процентом скидки
- Кнопка wishlist
- Информация о цене (текущая и оригинальная)
- Кнопка "Купить" с эффектом hover

### `CategorySection` - Секция категорий
- Заголовок категории
- Сетка товаров (1 колона на мобиле, 2 на планшете, 4 на десктопе)
- Автоматическая фильтрация товаров

### `Footer` - Подвал сайта
- Контактная информация
- Ссылки на помощь
- Информация о компании
- Социальные сети

## 🎨 Дизайн и стилизация

- **Фреймворк:** Tailwind CSS
- **Цветовая схема:** Минималистичная с черно-белой основой и красными акцентами
- **Шрифт:** Inter
- **Адаптивность:** Mobile-first подход
  - Мобиле (320px+)
  - Планшет (768px+)
  - Десктоп (1024px+)
